## Краткое описание
Программное приложение на C++ (Windows API), моделирующее задачу «Писатели-читатели» с приоритетом писателей. Используются семафоры и критические секции для синхронизации.

## Требования к среде
- ОС: Windows
- Компилятор: MSVC (Visual Studio) или MinGW (g++)
- Сторонние библиотеки не требуются.

## Инструкции по сборке
1. Открыть файл `src/main.cpp`.
2. Скомпилировать командой: `g++ src/main.cpp -o lab4.exe`
3. Запустить `lab4.exe`.

## Параметры запуска
Программа поддерживает аргументы командной строки:
`--readers <число>` - количество читателей (по умолчанию 3)
`--writers <число>` - количество писателей (по умолчанию 2)
`--ops <число>` - количество операций на поток (по умолчанию 200)

Пример: `lab4.exe --readers 3 --writers 5 --ops 50`

## Порядок воспроизведения экспериментов
1. Запустить `lab4.exe --readers 3 --writers 2 --ops 50` (3 раза).
2. Запустить `lab4.exe --readers 3 --writers 5 --ops 50` (3 раза).
3. Зафиксировать время выполнения (Execution Time).
4. Запустить скрипт `scripts/plot.py` для построения графиков по полученным данным.
